# Дизайн-документ: Модернизация интерфейса Levitate API Console

Этот документ описывает концепцию и спецификацию редизайна панели управления Levitate Console на основе предоставленного пользователем карт-бланша и принципов премиум-дизайна (Awwwards-Tier / Linear-tier).

## 1. Проблемы текущей версии
1. **Дублирование заголовков:** На каждой вкладке дублируется название (оно выводится и в глобальном заголовке `DashboardLayout`, и локально в контенте вкладки).
2. **Дёргание компонентов при смене языка:** Переключение языков (EN/RU) меняет длину слов, из-за чего плашки, кнопки переключателей и колонки сдвигаются.
3. **Дефолтная типографика:** Использование шрифта `Inter` (который считается стандартным/дефолтным в премиальном дизайне). Отсутствие кириллического сабсета для моноширинных элементов.

---

## 2. Проектное решение

### А. Типографика (Plus Jakarta Sans & JetBrains Mono)
- **Основной шрифт (sans):** **Plus Jakarta Sans** — современный геометрический гротеск с превосходными кириллическими символами и стильным начертанием.
- **Моноширинный шрифт (mono):** **JetBrains Mono** — один из самых красивых и читаемых моноширинных шрифтов для отображения логов, токенов и ключей с полной поддержкой кириллицы.

### Б. Устранение дублирования заголовков
- Удалить глобальный `<header>` из [DashboardLayout.tsx](file:///C:/Repos/levitate-api/frontend/src/components/DashboardLayout.tsx).
- Внедрить локальный заголовок и описание в [OverviewTab.tsx](file:///C:/Repos/levitate-api/frontend/src/components/OverviewTab.tsx) для единообразия со всеми остальными вкладками.
- Каждая вкладка сама управляет своей шапкой (заголовок, описание и кнопки действий в одну линию).

### В. Стабилизация размеров (Устранение сдвигов)
- Задать фиксированную ширину для переключателей языка и темы в сайдбаре и мобильной шапке.
- Задать фиксированную минимальную ширину для элементов статусной плашки `.mc-strip` на вкладке Overview, чтобы смена статуса не меняла размеры плашки.
- Обеспечить жесткую ширину колонок в таблицах.

### Г. Эстетика и микро-анимации (Double-Bezel & Glassmorphism)
- Оформить панели таблиц и карточки по технологии **Double-Bezel** (nested architecture):
  - Внешний контейнер: `bg-white/[0.02] border border-white/5 rounded-2xl p-1`
  - Внутренний контейнер: `bg-[#1a1b1e] border border-white/5 rounded-[calc(1rem-0.25rem)]`
- Кнопки действий перевести в формат скругленных пилюль (`rounded-full`) с вложенным круглым контейнером для иконки.
- Добавить пружинные анимации `ease-[cubic-bezier(0.32,0.72,0,1)]` с длительностью `700ms` для всех интерактивных переходов (hover, focus, active).
